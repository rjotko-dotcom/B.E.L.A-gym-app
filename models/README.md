# models/anatomy.glb

The 3D body (`js/body3d.js`). 221 muscle meshes plus skeleton, connective
tissue and head/hands/feet as context, each node carrying `extras`
(`muscleId`, `key`, `label`, `group`, `layer`, `side`, `region`).
